Try it with your own Sheet

  1. Open the published template or import the downloaded JSON into a new, empty n8n workflow.
  2. Install the verified Apify community node if required. Select your Apify credential on every Apify node and your Google Sheets credential on the Sheets node.
  3. Create a blank Sheet tab named Booking Shortlist. Import the header CSV as its first row.
  4. In Shortlist settings, enter the destination, future stay dates, spreadsheet ID and tab name. Start with 5 properties and keep the existing $0.10 maximum Actor charge per run.
  5. Run manually. Inspect the Sheet, coverage and charge receipt before repeating. A capped result is a shortlist, not the whole market.

The workflow download is free. Apify usage and your n8n hosting/plan may cost money. The $0.10 value is a cap, not a price promise. No schedule needs to be activated for this demonstration.
